# Source Code (src)

This folder contains the TypeScript source code that drives my website's functionality.

## Subfolders

- `buttons/`: Contains TypeScript classes and interfaces for various interactive buttons (e.g., Github, Play, and Use buttons).
- `projects/`: Handles the logic for displaying projects and their descriptions. It also includes HTML templates for project details.
- `setup/`: Initialization scripts responsible for setting up projects and creating page titles.

## Key Files

- `main.ts`: Entry point for the website: runs `main()` once DOM is loaded.
