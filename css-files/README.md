# Stylesheets (css-files)

This folder contains the CSS files used to style various components and sections of the website.

## Files

- `buttons.css`: Styles for interactive buttons on project-cards. 
- `gordie.css`: Literally just for hovering over **gordie** on the website. 
- `project-desc.css`: Layout and styling for project description panels and content.
- `projects.css`: Styles for project cards and their layout in the projects section.
- `wave.css`: Animation for the title of the website (gordienovak.com)
