# gordienovak.com

This is my personal website projects to host my projects, resume, and other things I find interesting.

It's currently hosted at [gordienovak.com](https://gordienovak.com) (believe it or not).

## Languages & Tools

- **TypeScript**: Used for all application logic, project management, and UI interactions.
- **HTML**: Provides the basic structure of the website.
- **CSS**: Handles the styling and visual effects of the site.
- **Vite**: Used for quick development, testing, compiling, and deployment.
- **pnpm**: Easy to use package manager. 

## Major Folders
- `src/`: Contains the TypeScript source code for the project's logic and setup.
- `css-files/`: Contains specialized CSS files for different components and sections of the site.
- `public/`: Static assets and resources. Contains `.wasm` & `.html` bundles to run each project.
